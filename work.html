Student-RENT-Z — AI-Native Rental Marketplace

full-stack · FastAPI + React

A multi-category student rental marketplace — students rent laptops, textbooks, dorm supplies, and housing — built end to end, from the database up through an AI-powered natural-language search experience.

  • Built a RESTful FastAPI backend (RentIt API) with auth, listings, and bookings, plus an AI natural-language search endpoint (/ai/search-properties).
  • Designed CRUD API endpoints for user and rental data management, backed by a relational database (PostgreSQL/MySQL) with structured SQL access.
  • Implemented request validation and backend business logic for reliable API operations, tested with Postman.
  • Built the React (Vite) + Tailwind CSS frontend: a category-aware AI search hero with smart prompt chips, a multi-category listings grid with badges for pricing/condition/location, and item-detail modals with rental terms and deposit info.
  • Wired the frontend to the backend through a modular src/services/api.js layer using Axios, with responsive styling, category tabs, and loading/empty states.

SafeWalk AI — Safe Route Recommendation

FastAPI + ML risk model

A web-facing route recommendation system: the backend serves safe-route queries by combining a pre-trained crime-risk model with graph-based routing, rather than only shortest-path.

  • Built the backend service exposing REST API endpoints to serve safe-route queries to client applications.
  • Designed the system architecture separating data ingestion, risk-model inference, and route-generation into independent, modular components.
  • Integrated a pre-trained ML risk-scoring model into the backend pipeline, wrapped behind a clean API layer for real-time inference calls.
  • Implemented graph-based routing with Dijkstra/A*, combining model-generated risk scores with distance metrics to compute safer paths.
  • Handled request validation, data access, and API testing with Postman for reliable end-to-end performance.
